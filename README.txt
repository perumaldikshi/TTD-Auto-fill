TTD AUTOFILL ASSISTANT
Features:
- General Details shared across booking: email, country, state, city, PIN code, address.
- Add User button for person-specific details.
- Edit and Delete each saved pilgrim.
- Local save, JSON backup export/import.
- Fill fields only; never submits bookings or bypasses CAPTCHA, OTP, queues, payments, or limits.

Install: extract ZIP -> Chrome chrome://extensions -> Developer mode ON -> Load unpacked -> select folder with manifest.json.
Use: enter common General Details; click Add User for each pilgrim; Save User; edit/delete as needed; click Save All Details; on official TTD form click Fill Current TTD Page. Check every field.
Sensitive ID details are stored in Chrome local extension storage. Exported JSON is not encrypted.
